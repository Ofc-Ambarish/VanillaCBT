# Universal CBT Competitive Examination Portal

A commercial-grade, client-side Computer-Based Test (CBT) platform designed for any objective competitive examination (WBPSC IDO, SSC, GATE, JE, UPSC, Railways, etc.).

## Highlights
- **Zero Preloaded Questions:** The database starts 100% clean. You import tests via CSV.
- **Dynamic Question Count:** Supports any number of questions per test (25, 50, 100, 200+).
- **Realistic Interface:** Standard 5-color palette, timestamp-based timer (refresh & tab-switch safe).
- **Offline Capable:** Pure HTML5, CSS3, Vanilla JS, and IndexedDB.

## Running the Application
1. Extract this ZIP archive.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Import your CSV question bank and answer key on any test slot.
